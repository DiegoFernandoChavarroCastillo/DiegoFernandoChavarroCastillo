## 🎮 Peerly

### Real-Time Virtual Environment

Microservicio encargado de gestionar la comunicación **en tiempo real** de la red social universitaria Peerly.

Implementa diferentes experiencias multijugador mediante WebSockets, incluyendo un mapa virtual, chat efímero, un duelo de fútbol 1v1 y una arena shooter 2D para hasta 6 jugadores.

**Highlights**

* ⚡ WebSockets con Socket.IO
* ⚽ Football Duel con física autoritativa
* 🎯 Shooter Arena multijugador
* 🧱 Arquitectura hexagonal
* 🔐 Autenticación mediante JWT
* 🧠 Estado efímero en memoria
* 🚀 Optimización de game loops
* 📊 Load testing y análisis de latencia

**Performance**

```text
P50 snapshot latency     ~31 ms
P95 snapshot latency     ~50 ms
P99 snapshot latency     ~52 ms
Tick rate under load     ~24 ticks/s
Concurrent players       6
```

**Stack**

`NestJS` `TypeScript` `Socket.IO` `Matter.js` `Jest` `JWT`

## 🛡️ Secuh

### Intelligent Video Surveillance

Sistema de videovigilancia inteligente capaz de procesar vídeo **en tiempo real** y detectar específicamente personas.

Puede trabajar con cámaras IP mediante RTSP, teléfonos móviles usando IP Webcam o webcams USB, enviando notificaciones al propietario mientras el evento está ocurriendo.

**Highlights**

* 👁️ MOG2 + YOLOv8n
* 📸 Evidencia fotográfica y clips de vídeo
* 📱 Notificaciones mediante ntfy y Telegram
* 🎥 Soporte para RTSP, IP Webcam y USB
* 🌐 Panel web con React + Vite
* 📡 Eventos en tiempo real mediante SSE
* 🔄 Reconexión automática de cámaras
* 🔐 Autenticación y rate limiting
* 🧱 Arquitectura hexagonal
* 🗃️ SQLite / PostgreSQL
* 🐳 Docker para producción

**Pipeline**

```text
Camera
   ↓
Motion Detection
   ↓
YOLOv8n
   ↓
Person Detected
   ↓
Evidence + Cooldown
   ↓
Notification
```

**Stack**

`Python` `FastAPI` `OpenCV` `YOLOv8` `React` `TypeScript` `SQLite` `PostgreSQL` `Docker`

# 🔬 More About My Projects

### 🎮 Peerly — Real-Time Engineering

One of the main challenges of Peerly is maintaining a responsive real-time experience while several clients interact simultaneously.

The project uses specialized game loops, object pooling, spatial hashing and pre-allocated buffers to reduce unnecessary allocations and improve runtime performance.

```text
Client
  │
  ├── WebSocket
  │
  ▼
NestJS Gateway
  │
  ├── Game Loop
  ├── Physics Engine
  ├── Collision System
  └── State Management
  │
  ▼
Real-Time Snapshot
  │
  ▼
Multiple Clients
```

### 🛡️ Secuh — Computer Vision

Secuh combines traditional motion detection with an object detection model.

Instead of running YOLO continuously against every frame, the system first uses **MOG2 as a movement pre-filter**, reducing unnecessary inference and allowing YOLOv8n to focus specifically on detecting people.

```text
        ┌──────────────┐
        │    Camera    │
        └──────┬───────┘
               │
               ▼
        ┌──────────────┐
        │     MOG2     │
        │   Movement   │
        └──────┬───────┘
               │
          Movement?
          /       \
        No         Yes
        │           │
        │           ▼
        │      ┌──────────┐
        │      │ YOLOv8n  │
        │      │  Person  │
        │      └────┬─────┘
        │           │
        │       Detected?
        │        /     \
        │      No       Yes
        │      │         │
        └──────┘         ▼
                    ┌──────────┐
                    │ Evidence │
                    └────┬─────┘
                         │
                         ▼
                    Notification
```
